Privacy Policy

Last updated: 21 November 2026

Who this applies to

Efe Clips Naija is a private tool used by one person (the owner) to upload video clips to the owner's own YouTube channel. It has no other users and does not collect information from the public.

What Google data the tool accesses

When the owner signs in with Google, the tool asks for one permission: to upload videos to the owner's YouTube channel (youtube.upload). It does not read the owner's email, contacts, files, watch history, comments or any other Google data.

How it is stored

The access token that lets the tool upload videos is stored in private, encrypted secrets on the owner's own GitHub account. It is not shared with anyone and is not used for any other purpose.

What the tool does not do

  • It does not sell, share or transfer Google user data to anyone.
  • It does not use Google user data for advertising.
  • It does not collect personal information about visitors to this page.

YouTube and Google services

The tool uses YouTube API Services. By using it, the owner is bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. The owner can remove the tool's access at any time at myaccount.google.com/permissions.
